## ✨ Features

- 🎮 Responsive 2D Platformer Controller
- 🦘 Jump & Double Jump
- 👾 Enemy AI พร้อมระบบตรวจจับผู้เล่น
- 🌋 Trap และ Hazard
- ❤️ Health & Life System
- ⭐ Real-time Score System
- 🎵 Background Music และ Sound Effects
- 💥 Particle Effects และ Animation
- 🚪 Level Progression
- 📱 รองรับการเล่นบน Web Browser

---

## 🎮 Controls

| Input | Action |
|-------|--------|
| **A / ←** | Move Left |
| **D / →** | Move Right |
| **Space** | Jump |
| **X** | Attack / Shoot |
